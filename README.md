# 지역 동향 모니터

지자체·유관기관 이름으로 **주요이슈 / 단체장 동향·브리핑 / 지원정책·공고** 기사를 모아 보는 웹페이지입니다.
휴대폰에서 열어 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 동작 방식

- **GitHub Pages**: 웹페이지(`index.html`)를 무료로 호스팅합니다.
- **GitHub Actions**: 매시간 `collector.py`가 `orgs.txt`의 기관 뉴스를 구글 뉴스에서 모아 `data/`에 저장합니다.
- **목록에 없는 기관**: 검색하면 공개 프록시를 거쳐 실시간으로 검색합니다. 프록시 상태에 따라 느리거나 실패할 수 있습니다.
  자주 보는 기관은 `orgs.txt`에 추가해 두세요.

## 처음 배포하기

1. GitHub에 **Public** 저장소를 만들고, 이 폴더의 파일을 모두 올립니다.
   (`.github` 폴더도 꼭 올려야 합니다.)
2. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main / (root)** 를 고르고 Save를 누릅니다.
3. 저장소의 **Settings → Actions → General → Workflow permissions**에서
   **Read and write permissions**를 고르고 저장합니다. 자동 수집 결과를 저장소에 저장하려면 이 권한이 필요합니다.
4. **Actions** 탭 → "뉴스 자동 수집" → **Run workflow**를 눌러 한 번 실행합니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 접속합니다.

## 휴대폰에 설치

- 안드로이드(크롬): 주소 접속 → ⋮ 메뉴 → **홈 화면에 추가** (또는 **앱 설치**)
- 아이폰(사파리): 주소 접속 → 공유 버튼 → **홈 화면에 추가**

## 기관 추가·삭제

GitHub에서 `orgs.txt`를 열고 연필(✏️) 버튼으로 고친 뒤 Commit하면, 몇 분 안에 수집이 반영됩니다.
기관명이 길어 검색이 잘 안 되는 경우는 자동으로 따옴표 없이 다시 검색합니다.

## 참고

- GitHub는 저장소에 **60일 동안 활동이 없으면** 예약 실행을 멈춥니다. 멈췄을 때는 Actions 탭에서 다시 켜면 됩니다.
- 기사 저작권은 각 언론사에 있으며, 이 페이지는 제목과 링크만 보여줍니다.
- PC 미리보기: `python server.py` 실행 후 http://localhost:8765 에 접속합니다.
